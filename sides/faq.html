FAQ

Quick notes for getting started with Farming Essentials.

Where can I download the mod?

The available JAR is on the Download page.

Which Minecraft version and mod loader do I need?

Compatibility details are not included with the current release file. Check the release information from the project maintainer before installing.

How do I install the JAR?

Use the installation steps for your Minecraft mod loader, and make sure the downloaded file matches the versions you run.

Can I use this on a server?

Check the mod's release notes or ask the server administrator to confirm whether it is supported on your server.
